# 手机端优化与真机验收清单

日期：2026 年 10 月 16 日。分支：`feat/mobile-touch-optimization`。基线：程序 0.3.0、规则 3、存档格式 1。
修改人：邹昊田（M5）。相关评审：林辉（M2，index.html / styles.css / app.js 界面部分）。

## 本轮改动

| 文件 | 改动内容 |
| --- | --- |
| index.html | 新增苹果 Web App 元信息（添加到主屏幕、状态栏样式、应用名）；关闭电话号码自动识别 |
| styles.css | 安全区适配（刘海与底部指示条不遮挡内容）；100vh 回退保证旧内核可用；iOS 输入框字号 16px 防页面自动缩放；触控目标统一 ≥44px；`touch-action: manipulation` 去点击延迟与双击缩放；去除 tap 灰色高亮与文本选中；悬浮态仅对鼠标设备生效（触屏不再粘滞）；iOS 惯性滚动；防止下拉刷新误触发 |
| app.js | 引擎不支持 `<dialog>` 时显示「请使用较新的浏览器」提示，而不是静默报错 |

规则、数值与存档结构零改动：`node --test game.test.js mvp.test.js` 41 项通过、0 失败；`node --check app.js` 通过。

## 支持的浏览器基线

项目已使用 `svh`、`inert`、`dialog`、`Object.hasOwn`、`Array.prototype.at` 等特性，有效基线为：iOS Safari ≥ 15.4、Chrome ≥ 92、Edge ≥ 92。低于基线的浏览器会看到升级提示（见 M07）。验收时记录实际设备与浏览器版本。

## 音效与背景音乐冒烟检查（分支 feat/audio-sfx）

音频由 Web Audio 在浏览器内实时合成：零外部素材、零授权风险，符合课程对素材来源的要求。背景音乐为 24 秒循环（四个和弦铺底加五声音阶旋律），声音开关偏好保存在独立的 `bjtu-life:audio:enabled` 键中，不进入存档格式。进入游戏流程本身要求浏览器支持 `dialog`；不支持 Web Audio 的旧环境自动静默跳过，开关按钮隐藏。

| 编号 | 检查项 | 步骤 | 预期结果 | 结果 | 设备与浏览器版本 |
| --- | --- | --- | --- | --- | --- |
| A01 | 点击与场景音效 | 点按钮、进入不同地点、执行学习/休息/锻炼等行动 | 按钮有轻微咔哒声；图书馆、思源楼、逸夫楼是学习音，宿舍、银杏大道是舒缓音，操场是运动音，南门、活动中心是机会音，事件弹出有铃声 | | |
| A02 | 背景音乐 | 入学后在地图停留约 6 秒 | 有轻柔循环背景乐，不刺耳、不影响操作 | | |
| A03 | 开关与记忆 | 点「声音:开」按钮，再刷新页面 | 音效与音乐全部静音；刷新后按钮仍显示「声音:关」，偏好被记住 | | |
| A04 | 切后台恢复 | 游戏中切到其他应用再切回 | 音乐停止后重新开始循环，无爆音、无叠音 | | |
| A05 | 结算与结局 | 结束学期、选择毕业方向 | 学期总结有报告感音效，毕业方向与结果有短号角 | | |

## 已知限制与后续建议

- 地图素材 `assets/campus-map-reference.png` 约 3.7 MB，移动网络下加载偏慢。压缩或转 WebP 需与 M2 林辉、M4 朱梓林确认素材来源与授权后处理。
- 旧微信浏览器若不支持 `<dialog>`，会提示改用系统浏览器，属预期降级而非故障。
- 横屏手机走桌面布局，可正常操作，未做专项优化。
