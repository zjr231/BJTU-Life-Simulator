# 第 3 批优化：NPC 对话生命周期

基于 `main` 的 `aaabd35`，日期：2026-10-30。

## 问题与修改

NPC 离场后，已打开的聊天窗口仍可能继续保留；在线回复返回时还可能写入已经不存在的人物会话，造成玩家与离场 NPC 继续聊天的错觉。

现在 NPC 离场会立即清理该人物的本地聊天记录和台词索引。如果玩家正在与该 NPC 对话，窗口会关闭并提示“已经离开了”，后续异步回复不会重新写入这段会话。NPC 淡出地图的视觉效果仍然保留。

## 验证结果

- `node scripts/check-release.js`：14 个发布文件检查通过。

- 新增回归覆盖 NPC 离场、聊天窗口关闭、会话清理和离场提示。

## 手动复查

1. 进入新局并等待地图出现 NPC。
2. 点击 NPC 打开聊天窗口，发送一条消息。
3. 等待 NPC 生命周期结束，确认聊天窗口关闭并显示离场提示。
4. 再次遇到其他 NPC，确认不会看到上一个 NPC 的聊天记录。
