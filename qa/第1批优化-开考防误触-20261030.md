# 第 1 批优化：开考防误触

基于 main 的 `7a6f25b`，日期：2026-10-30。

## 问题与修改

原来点击“结束学期并考试”会立刻生成试卷、锁定本学期行动。剩余时间较多时误点，玩家无法返回继续学习。

现在先显示确认框，列出剩余时间、当前平时分、成绩比例和开考后果。“继续安排”或 Esc 返回本学期；“确认开考”才执行原来的开考与自动保存逻辑。打开和取消确认框都不修改游戏状态，不生成试卷、不写存档。时间用完时同样需要确认。

这批只修改开考入口和对应测试、说明，规则与存档格式沿用当前 main。

## 验证结果

- `node --test`：155 项全部通过，其中界面测试 28 项，本批新增 6 项。
- 新增回归覆盖打开与取消不改变状态、重复点击只开考一次、确认后才自动保存、刷新恢复同一试卷、零时间确认、过期确认拒绝，以及待处理事件优先展示。
- `node scripts/check-release.js`：14 个发布文件检查通过。
- `git diff --check`：通过。

本机 Chrome 155.0.8059.85 与 Edge 156.0.4314.50 使用无头模式、独立临时配置和本地 HTTP 服务完成真实界面点击：入学选课、学习、保存到栏位 2、打开确认、Esc 返回、再次打开并选择继续安排、继续学习、确认开考、刷新读档。两者均恢复同一试卷，开考记录只有一次，无脚本或资源请求错误。

确认框在 1440×960、390×844、360×740 视口下均无横向溢出，取消和确认按钮可点击。窄屏检查为浏览器模拟，尚未进行手机真机验收。

## 手动复查

1. 新局选 3 门课，完成一次课程学习，然后点击“结束学期并考试”。
2. 确认框应显示剩余时间 10 点、平时分 20 / 100。选择“继续安排”后可继续学习。
3. 再次打开确认框，点击“确认开考”，应显示 5 道试题。
4. 若开考前已选存档栏位，刷新页面并读取该栏位，应直接恢复同一份试卷。
