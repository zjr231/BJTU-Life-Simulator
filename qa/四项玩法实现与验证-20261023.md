# 四项玩法实现与验证

本地版本 0.4.0，规则版本 3、存档格式版本 1。日期：2026-10-23。

## 可体验的变化

1. 每学期开学选择一个目标：学业冲刺、连接校园、积累实践、照顾自己或走出熟悉区。进度实时更新，学期结算发放一次完成奖励；未完成不发奖励，结算预览不会修改状态或重复奖励。
2. 室友、指导老师和社团伙伴有独立关系值，范围 0～100，跨学期保留。行动与事件选项会改变关系，可在“本学期目标”和成长记录中查看数值及专属事件门槛。
3. 增加室友出行、老师推荐、社团主理三项关系事件。选项展示资源和关系成本；接受留下永久经历并关闭重复触发，导师推荐和社团主理会影响毕业方向。拒绝保留相应后果，也允许在后续符合条件的学期重遇。
4. 增加校园组织者、身心平衡、创新实践者三个毕业方向。与原三个方向一起逐项展示门槛，满足多个方向时可自主选择。未满足基础毕业条件仍进入原有未达标结果。

三栏存档保存全部新字段。0.3.1 同规则旧档的五种阶段都可以读取，补齐初始关系和未选目标记录，保留已有课程及毕业结果。只迁移全部新增字段都缺失的旧档，损坏或部分缺失的新字段交给校验拒绝；旧毕业条件快照也先核实后补入新选项。

## 浏览器验收

使用本机 Chrome 155.0.8059.85 与 Edge 155.0.4283.62 的无头模式、独立临时用户配置和本地 HTTP 服务。测试不接触用户的正常浏览器存档。

两种浏览器均通过真实界面点击走完八学期：每学期选目标，完成社团、接下主理活动、选择校园组织者并自动保存到栏位 2；刷新后从入学页恢复同一最终状态，操作日志重放与最终状态完全一致。
