# 事件系统审计与改进

日期:2026 年 10 月 25 日。分支:`feat/events-audio-npc`。基线:程序 0.3.1、规则 3、存档格式 1(事件改动不涉及存档格式)。
修改人:邹昊田(M5)。审计依据:config.js / game.js 现状与北京交通大学官方新闻、招生网、校友会等公开资料对照。

## 一、现状盘点(改进前)

共 38 个事件:状态必发 4、固定日程 4、事件链 14、随机日常池 16。

| --- | --- | --- |

| | 补考通知 | 上学期挂科 |
| | 毕业季 | 第 8 学期末 |
| 固定日程 | 军训开训 → 汇演 | 第 1 学期初 |
| | 转专业通知 | 第 3 学期中段(仅一次,无结果) |
| | 深造宣讲会 | 第 6 学期中段 |

## 二、审计问题与对应改进

| # | 问题 | 依据 | 改进 |
| --- | --- | --- | --- |
| A1 | 体测为"报名制+春季",与现实不符 | 北交体测为每学年秋季全员主测,春季补测 | 改为秋季学期(第 3/5/7 学期)全员必发"体测周";参加按体能判定达标(≥60 留经历)或不达标(标记春季补测);请假直接标记补测;春季(第 4/6/8 学期)新增"春季补测"事件 |
| A2 | 转专业申请后无结果 | 校方文件:大一下/大二上/大二下共 3 次机会,转入有考核,平均成绩优异者优先 | 申请窗口改为第 2-4 学期;新增"转专业结果"事件(下学期初),按已结算平均成绩 ≥ 85 判定:成功换学院方向并改变背景加成,失败明年可再试 |
| A3 | 运动会完全缺失 | 北交每年举办春季运动会、院际杯、体育节 | 新增"春季运动会"事件(第 2/4/6 学期):短跑接力按体能出结果、趣味项目保底、观众席 |
| A4 | 伤病"硬扛"无后果 | 事件选项应有取舍 | 崴脚忍着扣体能/心情、流感硬扛扣心情、失眠硬睡扣心情 |
| B5 | 竞赛招募与决赛挤在同一学期 | 校内选拔秋季启动、决赛次年春季 | 决赛改为第 6 学期(跨学期链) |
| B6 | 军训内容单薄 | 北交军训含拔河、红歌合唱、分列式、军体拳等 | 开训增加拔河/红歌选项;汇演增加合唱方队选项 |
| B7 | 银杏季缺席 | 银杏大道 10 月底-11 月中为招牌景观 | 新增"银杏大道金黄"随机事件(秋季,散步后) |
| B8 | 红果园(山楂)缺席 | 秋天后勤采摘山楂分发师生,交大学子昵称"小红果"由来 | 新增"山楂分发"随机事件(秋季,锻炼后,山楂林在逸夫操场旁) |
| B9 | 校友活动可再补 | 值年返校大会、文创集市真实存在 | 新增"校友返校集市"随机事件(宾馆志愿后) |
| C10 | 五处建筑零随机事件 | 覆盖审计 | 思源楼"课堂点名"、南门"招聘会海报"、校医院"医保办理"、逸夫楼"实验室通宵"、活动中心"周末舞会" |
| C11 | 食堂文案虚构 | 北交真实餐厅:益民餐厅、明湖餐厅、学活餐厅 | "食堂三楼"改为"益民餐厅",保持群消息触发(地图暂无食堂建筑) |
| C12 | 歌手大赛名称 | 北交传统活动名为"校园歌星大赛" | 链名改为校园歌星大赛;新增"12·9 文艺汇演"随机事件(秋季末,看演出后) |

## 三、改进后规模

事件 38 → 50 个:日程新增体测周(3 季)/春季补测/转专业结果/春季运动会,随机池 16 → 25 个,事件链修正 2 条(竞赛跨学期、军训支线)。
