# 校园养成 × 四维预算合并说明（二期）

日期：2026-11-04
程序版本：0.8.0
规则版本：3（不变）
存档格式版本：1（不变）
`growth.version`：1（不变，只增单品不改结构）
`BUDGET_CONFIG_VERSION`：2（不变，未修改任何档位数值）

## 背景

0.7.0 的四维学期预算让玩家每学期为衣/食/住/行各选一个档位。这个模型按用户定位是**过渡态**——真实生活不是每维一个档位，而是"固定底座 + 具体单品"。队友的校园养成系统（一次性购买、本局持续、带前置条件）正是最终形态的雏形。本期把两者合并：

1. 衣/食/行退化为**固定底座**，住宿保留三档可选；
2. 旧档位（精致/品鉴家等）标记 `legacy`，仅用于旧存档快照兼容，界面不再提供；
3. 养成系统泛化为通用单品框架，承载九个单品（原三件 + 新增六件）；
4. 养成面板重排为 衣/食/住/行/习惯 五组，并统一为全站深绿玻璃面板风格。

## 单品 Schema

`config.js` 的 `GROWTH_NODES` 从"每节点一组专用字段"改为统一 schema：

```js
{
  id, icon, dimension, category, title, price, description, benefit,
  prereq: { minTerm?: number, actionCounts?: { [actionId]: number } },
  effects: [
    { kind: 'action', actions: ['rest'], bonuses: { recovery: 3 } },              // 行动固定加成
    { kind: 'action', actions: ['rest'], bonuses: { mood: 2 }, perTerm: 2 },      // 每学期限次
    { kind: 'termStart', bonuses: { energy: 3 } }                                 // 开学加成（仅精力）
  ]
}
```

约束：

- 加成只允许**正向追加**收益键（recovery/mood/fitness/social/preparation/furtherStudy/jobPreparation），无折扣、无倍率、无金钱；
- 应用顺序固定为：住宿倍率 → 体能档位缩放 → 宿舍交流修正 → **养成固定加成**，因此固定加成不会被二次放大；
- `perTerm` 按"购买后本学期的**原始行动次数**"计数，属性已满也占用次数；
- 进入 `entry.growthBonuses` 的键：`energy` 与 `mood` 恒存在（既有测试与旧界面兼容），其余键仅在非 0 时出现。

`GROWTH_DIMENSIONS` 定义面板分组顺序：衣 / 食 / 住 / 行 / 习惯。

## 学期预算面板

- 衣/食/行为固定底座行（显示费用与效果，无按钮），住宿为三档按钮；
- `selectBudgetTier` 只接受 `housing`，其余维度点击无效（规则层 `chooseBudget` 仍接受任意合法组合供测试与直调）；
- `chooseBudget` 命令、grant 快照、`BUDGET_CONFIG_VERSION` 严格校验全部未变；
- 目标：开学只需确认一次，弹性升级走校园养成面板。

## 存档与校验

- `state.growth` 仍在首次购买时创建，`{ version: 1, purchased: { id: { term, revision } } }`；
- 新增单品只是往 `GROWTH_NODES` 里增加条目，旧购买的 id 仍可解析，无需迁移；
- `state-validation.js` 的购买审计改为 schema 驱动：`prereq.actionCounts.rest`、是否存在 `termStart` 效果、`prereq.minTerm`；
- `growthBonuses` 审计：允许键集合扩大，每键上限 = 已购节点中匹配本次行动的加成之和（`recovery` 映射为 `energy`），并保留重放精确比对。

## 界面风格统一

养成面板从深紫灰（#292535、双线框、硬偏移阴影）改为全站深绿玻璃语言：

- 面板：`rgba(14,36,30,.96)` + blur + 1px 暖白边 + 圆角 16；
- 标题：金色 `#f4d77c`；关闭钮改为 30px 圆形并保留按压反馈；
- 顶部为 衣/食/住/行/习惯 五个维度标签，点击切换后下方只渲染该维度的内容；标签带"已拥有/总数"小计数；
- 每个单品独立成卡（含图标、价格签、名称、状态），卡片本身按状态着色描边，不再共用一个维度大卡片；价格签改为金色胶囊；
- 状态色：已拥有绿 `#4a8a5c`、可添置金、余额不足红 `#a03737`、未满足灰；
- 购买按钮：实心金色 + 圆角 4 + `:active scale(.94)`；
- 图标保留像素风格，但统一到全站五色板（纸/金/深绿/绿/墨 + 木色）。
