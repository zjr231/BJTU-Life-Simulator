# 校园成长分支规划

本轮范围已经确认：先改节点界面、配置图标，整理后续分支方案。本文件中的新节点、活动、价格和收益均为建议，尚未加入游戏。

## 已完成的界面

保留地图左侧“校园养成”入口，打开后使用深紫色节点面板：左侧显示所选节点的图标、说明、收益、条件和购买按钮，右侧显示图标节点。绿色表示已拥有，米金色表示可添置，灰色表示条件未满足，红色价格表示余额不足。已锁定节点也可以点击查看详情，点击图标不会扣钱。

现有寝具与兴趣角独立购买；“累计休息 → 规律作息计划”显示实际前置条件和进度。手机上节点图在前、详情在后，选择节点后滚动到详情，关闭按钮始终留在顶部。现有三个节点的价格、收益、存档和购买规则沿用上一版。

## 分批落地

1. **界面与图标：本轮完成。** 将可选择的图标节点、详情面板、状态颜色、条件连线和手机布局做好。
2. **学习分支：下一批建议优先实现。** 接入基础工具和作品计划，把自学、项目投入、作品展示串起来。先利用已有项目行动，不重做项目主线。
3. **兴趣分支：单独一批。** 新增兴趣练习和校园小展演，让器材开启实际行动；展演是小型校园活动，歌手大赛继续保留自己的报名、复赛和决赛流程。
4. **生活扩展与平衡：再一批。** 加入室友共同布置和纪念记录，试玩八学期的收支、时间和收益，调整前几批数值。
5. **固定人物关系：以后另做。** 先建立固定角色、熟悉程度、共同经历与存档，再接人脉节点。当前随机偶遇 NPC 不足以独立承担长期关系分支。

## 实现前需要的衔接

现有学习、项目、室友交流、钱包、操作历史和三栏位存档已经能支持前置判断。后续需要增加两类能力：

- 节点配置增加 `requires`（已购节点、累计行动次数）和 `unlocks`（开启哪些行动），由同一规则入口计算解锁条件和界面连线。
- 兴趣练习、作品展示等加入行动配置与对应地点；购买、行动次数、效果、经历统一记录进操作历史，并补充存档校验白名单和重放逻辑。

继续保留现有节点 ID 与购买记录。新增可选字段只在使用新内容时写入，旧存档的缺省值视为尚未开始。图标由节点的 `icon` 配置指定，对应界面中的图标字典。

## 平衡约束

- 基础节点价格控制在 150～300 元。预算较紧家庭选择普通生活预算后，每学期约有 400 元新增可支配金，前期就能尝试一个节点。
- 进阶节点同时要求实际行动。宽裕家庭也需要完成练习与经历。
- 新节点的被动数值加成使用固定小额和学期上限，避免与住宿、体能倍率重复放大。基础工具与现有配套学习资料分别计算，上述方案合计每学期最多额外增加 6 点学习进度。
- 每学期仍只有 12 点时间，新活动每次 1 时间，并在一次行动确认前显示完整成本。优先考虑作品、兴趣新活动合计每学期最多两次，减少流程挤压。
- 以后可加入社团共享器材或借用路径，用参与活动换取尝试机会；先测试基础路线，再决定共享路径是否保留永久收益。
- 验证普通与预算较紧家庭的八学期路线、提前买完与后期才购买、属性封顶、重复点击、跨学期、旧档和三栏位存读档。
