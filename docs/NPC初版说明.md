# NPC 初版 v0.1

游戏程序版本：0.5.9。基于 main 开发，规则版本 3、存档格式版本 1。

本版先完成一名可持续交往的校园人物“周宁”，为后续增加其他 NPC、人物事件和恋爱模块提供基础。

## 体验入口

使用静态 HTTP 服务运行项目，打开页面；新玩家第一次成功在图书馆自主学习后，会认识同年级男同学周宁。认识后，可以从“关系 → 查看人物与互动”或地图地点中的“联系周宁”继续交流。

对话场景以人物立绘为主体，底部可自由输入，右侧提供当前情境的快捷回应和活动入口。人物资料可查看三项能力、状态、喜好、目标及共同经历，桌面和手机均可使用。

## 人物与互动

周宁慢热、认真，擅长整理笔记，也喜欢运动、散步和演出；他对上台表达有些紧张。人物拥有独立心情、精力和目标，可以参与目前 25 项地图行动，具体安排仍受年级、资源、健康、事件前置条件和人物精力限制。

相识度随交流和共同经历增长。聊天成长每学期最多 8 点，同类话题不重复刷取；正式互动每学期最多 4 次，前两次正常成长，后两次轻量成长。达到相识度 30 且有过共同活动后，可解锁陪周宁练习课程展示的个人事件。

周宁会在合适的行动之后主动联系玩家，包括关心疲惫状态、提出共同活动和鼓起勇气请求陪练。他也可以在课程讨论、台阶上的猫、占座之争、初雪、银杏大道、毕业大戏这六类校园事件中偶遇玩家。主动联系与事件偶遇合计每学期最多 2 次，并有行动间隔。

## 自由对话与 Agent 行为

沿用 `config.js` 中已有的 DeepSeek 云端中转地址。密钥保留在云函数环境变量 `DEEPSEEK_API_KEY` 中，本版没有在前端存放密钥，也不要求重新部署现有中转。

模型接收人物设定、双方真实状态、NPC 能力、共同经历、重要话题、最近对话和当前可用活动，可以自然交谈并提出活动意图。现有中转返回文字，因此本版使用结构化回复承载有限工具意图：

```json
{"say":"要不要沿银杏大道走走？","intent":"walk"}
```

游戏校验活动 ID 和条件后展示邀请。玩家答应后才执行真实活动，可以点击快捷回应，也可以输入“好，走吧”“可以”等明确答复；邀请会展示游戏资源成本。自由聊天不扣游戏时间、精力或金钱。篮球仍进入原投篮小游戏，完成后按真实命中结算。

模型不能直接修改属性、跳过条件或伪造完成结果。纯文本在线回复只用于闲聊，格式错误、无效意图或断网时回退到本地对话。迟到回复不会覆盖已经切换的进度。

## 三项能力与辅助收益

| NPC 能力 | 周宁初始值 | 主要用途 |
| --- | ---: | --- |
| 学业能力 | 80 | 学习、自习、补习、深造与项目 |
| 社交能力 | 45 | 交流、社团、日常与合作 |
| 运动能力 | 60 | 锻炼与球类活动 |

没有额外的“认真程度”。综合活动按需要组合能力，例如课程展示使用学业 60%＋社交 40%。

结算遵循“玩家先结算、NPC 后辅助”：先按原投入和随机结果生成收获，计入玩家体能挡位、相关能力和心情，再叠加小幅 NPC 加成。

玩家相关能力与心情的增益比例为 `25% ×（相关能力 × 75%＋心情 × 25%）÷100`，只修正活动相关的正向收获。玩家学业使用本学期学习进度，有历史成绩时与历史均分取平均；社交、运动分别使用现有社交和体能。独自行动与同行的玩家初始收获使用同一算法和同一次随机结果。

NPC 根据对应能力、相识度、心情与精力发挥辅助，且同时受两项上限约束：

```text
NPC 加成 ≤ 玩家初始正向收获的 8%
NPC 加成 ≤ 玩家属性产生的正向增益的 30%
```

取计算值和两项上限中的最小值。没有玩家正向属性增益时，NPC 数值加成为零；收益保留两位小数，辅助向下截取，不设置保底加 1。结算和成长记录分别显示玩家初始收获与 NPC 辅助。

新结算停用旧关系规则中的固定属性加点。NPC 不改变申请资格、事件结果档位、篮球命中或原费用，也不替玩家抵消负面结果、额外增加医疗恢复。相识度成长与人物记忆独立保留。

## 存档与代码接口

对话、未答复邀请、人物状态、能力及共同经历随存档恢复。新结算命令记录 `npcSupportVersion: 1`；旧命令继续按历史版本回放，已经发生的结果不会重新计算。新辅助账目和最终状态会与操作历史核对，支持小数收益、考试成绩和跨学期保存。

| 文件 | 职责 |
| --- | --- |
| `relationships.js` | 人物设定、能力、关系成长、生活状态与经历 |
| `character-agent.js` | 模型上下文、意图解析、主动时机与离线回退 |
| `character-scene.js` | 立绘对话界面渲染 |
| `npc-support.js` | 玩家贡献和 NPC 辅助上限 |
| `game.js` | 对话、邀请、同行与事件的统一结算和回放 |
| `state-validation.js` | 人物状态、小数收益与辅助记录校验 |
| `app.js`、`styles.css`、`index.html` | 交互入口、异步生命周期与界面接入 |

立绘与场景背景位于 `assets/characters/zhou-ning-casual-v1.png`、`assets/scenes/campus-afternoon-v1.png`，为本项目生成的运行素材。现有发布检查同步更新资源和脚本加载清单。

本次提交为 **NPC 初版**，仅包含功能代码、必要运行素材及说明文档；不新增或更新测试用例，不包含开发截图、日志、临时文件、本地预览脚本或密钥。
