# 提交后推送工作总结到飞书群

每次提交后，本机自动把「本次提交做了什么」推送到飞书群。实现是一个 git 钩子加一个小脚本：

- `.githooks/post-commit`：随仓库分发的钩子，提交完成后在后台启动脚本，**不阻塞 commit**，失败也不影响提交
- `scripts/feishu-notify.js`：读取提交信息与改动统计，调用本机 `claude -p` 生成 2～3 句中文总结，再用群机器人 webhook 发出去
- `.git/feishu-webhook`：每人本机的 webhook 地址，位于 `.git` 目录内，**永远不会被提交到仓库**

钩子通过 `core.hooksPath` 指到仓库内的 `.githooks/`，所以每位成员 clone 后只需「启用钩子 + 填 webhook」两步，不用手抄脚本。

## 一、准备群机器人

1. 打开飞书群 → 群设置 → 群机器人 → 添加机器人 → **自定义机器人**
2. 按需开启「签名校验」（建议开启）
3. 复制 webhook 地址（形如 `https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx`）

## 二、填写配置

在仓库根目录执行（把地址和密钥换成自己的）：

```bash
printf 'https://open.feishu.cn/open-apis/bot/v2/hook/你的地址\n你的签名密钥\n' > .git/feishu-webhook
```

- 第 1 行：webhook 地址
- 第 2 行：签名密钥；没开签名校验就留空
- 该文件只在本地，换机器或重新 clone 后需要重新填写，并重新安装钩子（见第五节）

## 三、先测试，再正式用

```bash
# 只打印将发送的内容，不真的发
FEISHU_NOTIFY_DRY_RUN=1 node scripts/feishu-notify.js

# 跳过 AI 总结，直接发一条（最快验证 webhook 是否可用）
FEISHU_NOTIFY_NO_AI=1 node scripts/feishu-notify.js
```

发送成功时脚本不输出；失败会提示飞书返回的错误码，日志同时写入 `.git/feishu-notify.log`。

## 四、推送内容示例

```
【北交人生】代码提交
项目：BJTU-Life-Simulator · 分支 main
提交：4da1469 · 2026-10-30 19:12 · msxlz
说明：合并主线 0.5.0：NPC 聊天规则结算与投入档位……
变更：34 个文件，+3852 / −554
总结：常规行动和部分事件改用固定投入档位……（AI 生成的 2～3 句）
```

AI 总结依赖本机 `claude` 命令（Claude Code）。没有该命令、超时或报错时自动退回只发结构化信息，通知不会中断。合并提交按相对主线（第一父提交）计算改动统计。

## 五、安装与卸载

钩子文件在仓库内，`core.hooksPath` 是每个 clone 的本地设置，所以新 clone 或换机器后执行一次：

```bash
git config core.hooksPath .githooks
chmod +x .githooks/post-commit   # macOS / Linux 需要；Windows 的 Git 不需要
```

再按第二节填好 `.git/feishu-webhook` 即可。

- 暂时关闭通知：删除 `.git/feishu-webhook`，或把首行改成非 http 内容，钩子会静默跳过
- 彻底卸载：`git config --unset core.hooksPath`
- 注意 `core.hooksPath` 会接管**全部** git 钩子；如果以后还加 `pre-commit` 等钩子，也放进 `.githooks/` 目录

## 六、团队复用

其他成员可以照着用，各自独立配置，互不影响：

1. `git pull` 拿到最新的 `.githooks/`、`scripts/feishu-notify.js` 和本文档
2. 执行 `git config core.hooksPath .githooks`（macOS/Linux 再加 `chmod +x .githooks/post-commit`）
3. 选一个 webhook 写进自己的 `.git/feishu-webhook`：
   - 想和大家发同一个群：直接用同一个群机器人地址
   - 想各发各的群：自己建一个自定义机器人
4. 可选：装好并登录 Claude Code（`claude` 命令可用）才有 AI 总结；没装也能用，会自动只发结构化信息，或用 `FEISHU_NOTIFY_NO_AI=1` 跳过 AI

建议团队约定：

- 每人用**自己的** webhook，或统一用一个专门的「开发日志」群，避免和通知群混在一起
- webhook 属于凭证，按密码对待；发错可到飞书群机器人设置里重置
- 提交信息写清楚（`feat/fix/docs` 开头 + 一句话），AI 总结会更准；仓库本身要求以 msxlz 等真实身份提交、不加 AI 署名，通知内容沿用这条规则

## 七、注意

- 只在**本机**生效，不会影响其他成员的提交
- webhook 与签名密钥不要写进代码、文档或提交信息
- 提交在终端、IDE 还是由 Claude Code 执行都会触发；脚本在后台运行，AI 总结约需 5～20 秒，群里稍后出现消息属正常
- 一次提交只发一条；连续提交会各自发送
