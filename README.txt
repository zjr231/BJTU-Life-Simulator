北交人生 · 地图 MVP

打开方式
1. 直接双击 index.html 即可预览。
2. 如果浏览器限制本地图片加载，可在此目录启动一个静态文件服务后打开 index.html。

当前范围
- 主校区手绘俯瞰地图
- 十一个可点击地点：学生活动中心、操场、思源楼、宿舍、校医院、图书馆、红果园宾馆、逸夫楼、南门、银杏大道、天佑会堂
- 地图底图直接使用用户提供的 Image1.png，页面只叠加透明交互区域
- 点击地点进入地点占位视图，点击“返回地图”回到地图
- 桌面端与手机端自适应布局
